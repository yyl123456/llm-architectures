## 2. 核心架构亮点与算法突破

1. **≤4B 端侧最高智能密度**：
   - 在 AA Tiny Models 排行榜中位居前二，以 2B 体积提供超越以往大体积模型的逻辑推理能力。
2. **端侧原生思考链 (MiniCPM5 Reasoning)**：
   - 首次在 2B 级别端侧小模型上原生部署强化学习长思维链，支持单张消费级显卡乃至智能手机本地离线运行。
