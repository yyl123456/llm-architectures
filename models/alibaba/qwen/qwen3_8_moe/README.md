## 2. 核心架构亮点与算法突破

1. **2.4 万亿参数开源物理极限**：
   - 包含 92 层超深 Transformer Decoder；
   - 512 个细粒度路由专家（每个专家 FFN 中间维度 2048），单 Token 激活 95B 计算量。
2. **沉淀研究方向**：
   - 超大规模专家网络在多机多卡上的 Expert Parallelism (EP) 与 Pipeline Parallelism (PP) 切分；
   - 92 层深层梯度的 QK-Norm 与稳定性控制。
