## 2. 核心架构亮点与算法突破

1. **原生统一多模态语言架构 (Native Multimodal Token Stream)**：
   - 彻底摆脱以往外挂 CLIP 视觉投影头的拼接架构，将高分辨率图像、视频帧和文本统一在同一个 64 层自回归 Transformer 解码器中端到端训练。
2. **长程软件工程与智能体代码能力**：
   - SWE-bench Pro 达 **61.7%**，Terminal Bench 2.1 达 **73.0%**；
   - 成为 2026 年开源社区部署量最大（670万+ 月下载）、综合性价比最高的单卡/消费级 24G 显存 Agentic 主力。
3. **沉淀研究方向**：
   - 64 层深度 Transformer 训练稳定化；
   - 248k 超大词表对多语言、代码及跨模态特征的压缩优势。
