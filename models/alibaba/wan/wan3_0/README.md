# Wan 3.0 (通义万相 3.0) 架构预研卡片

---

## 1. 基本概览

| 属性 | 说明 / 指标 |
|---|---|
| **模型名称** | Wan 3.0 (wan3.0-video & wan3.0-video-prime) |
| **开源机构** | 阿里巴巴 (Wan-AI / 通义实验室) |
| **发布时间** | **2026-09-04** |

| **官方代码库** | [wanvideo/wan-3-0-video](https://huggingface.co/wanvideo/wan-3-0-video) |

---

## 2. 核心架构亮点与算法突破

1. **原生音视频一体化多模态生成 (Native Audio-Video All-in-One)**：
   - 彻底打破以往“先生成无声视频，再外挂音效模型合成”的割裂范式；
   - Wan 3.0 在 DiT 内部将高保真声学波形特征与 3D 视频潜在向量联合建模，生成的视频人物说话口型、环境碰撞物理音效实现原生帧级音画同步。
2. **多角色与物理世界高保真一致性 (Reference-Video Consistency)**：
   - 支持跨镜头四维一致性（人物面部微表情、肢体动态、道具结构、光影风格与空间透视）；
   - 针对 AI 视频生成常见的“假面孔/千人一面”顽疾进行专项重构，支持多人复杂交互场景。
3. **沉淀研究方向**：
   - 3D 因果 VAE 的多模态音频时间切片嵌入机制；
   - `wan3.0-video-prime` 的去噪步数自适应跳步蒸馏方案。
