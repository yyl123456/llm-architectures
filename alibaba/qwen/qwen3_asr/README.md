## 2. 核心架构亮点与算法突破

1. **极端高吞吐与超低实时率 (Extreme RTFx)**：
   - 官方评测词错误率 (WER) 仅为 **5.75%**；
   - 推理速度指标 **RTFx 高达 835.6**，较传统 Whisper 大幅提速，极适合企业大规模音频转写。
2. **毫秒级字级别对齐 (ForcedAligner)**：
   - 附带 0.6B 强制对齐模型，能够毫秒级定位音频流与文本 Token 的精准对应时间戳。
