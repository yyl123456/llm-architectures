## 2. 核心架构亮点与算法突破

1. **流匹配扩散变换器 (Flow-Matching DiT)**：
   - 采用整流流匹配算法（Rectified Flow），相比传统 DDPM 采样步数更少、收敛更稳定。
2. **中英文字符排版渲染突破**：
   - 针对传统图像生成模型文字乱码的顽疾，深度融合 Qwen 文本理解能力，支持复杂中文书法、英文招牌与海报排版精确生成。
