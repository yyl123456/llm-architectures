## 2. 核心架构亮点与核心算法

### 2.1 SuScaledRoPE (长上下文长短因子自适应扩展)
- 为了使仅有 3.8B 的小模型能够从 4k 外推至 128k 超长上下文，Phi-3/4 提出了 SuScaledRoPE 机制：
  - 对短波长和长波长频率维度采用差异化缩放策略，保持局部注意力的精细分辨能力，同时平滑长距离位置外推。

### 2.2 极致紧凑网络配置
- 凭借微软独创的“教科书级高质量合成数据 (Textbooks Are All You Need)”与精细配比，模型层数多（如 3.8B Mini 具备 32 层）、隐藏层维度适中（3072），以极高参数效率逼近甚至超越 2-3 倍体积的同类大模型。
